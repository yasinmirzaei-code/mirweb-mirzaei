# MirWeb — Yasin Mirzaei, Creative Developer

Personal portfolio website (HTML + CSS + JavaScript, no build step).

## Structure

```
index.html        page structure and content
css/style.css     all styles
js/main.js        animations and interactions
assets/           favicon and static files
```

## Run locally

Open the folder in VS Code, install the **Live Server** extension, right-click `index.html` and choose **Open with Live Server**.

## Deploy on GitHub Pages

1. Push this folder to a GitHub repository (`index.html` must be in the repo root).
2. Go to **Settings → Pages**.
3. Under **Branch** choose `main` and `/ (root)`, then Save.
4. The site will be live at `https://USERNAME.github.io/REPO-NAME/`.

## Libraries (loaded from CDN)

GSAP + ScrollTrigger, Lenis, Inter (Google Fonts). An internet connection is required.
